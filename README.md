# **Bootcamp Itaú - Java com Inteligência Artificial**

Repositório de estudos do [**Bootcamp Itaú - Java com Inteligência Artificial**](https://www.dio.me/bootcamp/itau-java-com-inteligencia-artificial) oferecido pela [DIO](https://www.dio.me/) em parceria com o Itaú.  
Aqui documento minha jornada aprendendo Java integrado com conceitos modernos de Inteligência Artificial, com anotações e desafios práticos.

---

## **📖 Sobre o Bootcamp**

O Bootcamp é uma formação prática com foco no desenvolvimento em Java (incluindo o ecossistema Spring) e na integração com Inteligência Artificial, abordando Machine Learning, IA Generativa e criação de agentes.

---
